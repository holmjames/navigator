# demo/

- `navigator.html`: the walkthrough as presented to Navan (names the company).
- `navigator-portfolio.html`: the same page with the company name removed, for jholm.co/navigator.

Both are single self-contained files: inline CSS and JS, Archivo and Geist Mono from Google Fonts, no dependencies. Five tabs: how it's built, a rep's morning, how data moves, how we'd build it, scale and pilot (with the run-cost calculator). Hash links open a tab directly (`#day`, `#data`, `#build`, `#scale`).
